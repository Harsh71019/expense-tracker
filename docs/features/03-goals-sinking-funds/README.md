# Goals and Sinking Funds

## Outcome

Extend the existing goal tracker with one-click Indian life-stage templates, deterministic target calculators, and an allocation waterfall that respects safety and verified free cash flow.

## Template catalogue

- Career pivot or sabbatical
- House down-payment buffer
- Parental medical contingency
- Annual travel or recharge
- Financial independence

Templates are versioned starting points. Instrument text describes generic risk, liquidity, and horizon categories rather than named products.

## Subfeatures

1. Template catalogue and one-click setup
2. Target calculators and assumption disclosure
3. Feasibility and priority waterfall

## Existing capabilities to reuse

Goals, manual and ledger-linked progress, goal priorities, recurring commitments, budgets, assets, typed client, and goal detail routes.

## Product boundary

Goals never own balances. A “fund goal” action opens a prefilled existing transfer or contribution flow. Emergency reserves cannot be double-counted as freely available funding for another goal.
