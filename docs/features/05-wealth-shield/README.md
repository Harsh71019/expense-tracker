# Three-Bucket Wealth Shield

## Outcome

Classify existing accounts and assets by financial function—emergency shield, stability anchor, or wealth engine—then compare current and user-configured target allocation and recommend future cash-flow routing when drift is material.

## Subfeatures

1. Bucket and liquidity classification
2. Current-versus-target allocation and drift
3. Rebalancing through future flows

## Existing capabilities to reuse

Accounts, assets, valuations, net-worth aggregation, recurring investments, goals, dashboard investment series, and salary plans.

## Product rules

- Bucket metadata references existing values; it never stores independent balances.
- Insurance is shown in safety/protection, not as an asset layer.
- Emergency liquidity is excluded from deployable growth capital.
- Initial rebalancing recommendations route new contributions; they do not instruct sales.
- Category-level instrument guidance only; no named scheme selection.
