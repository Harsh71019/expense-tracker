# Freedom Projections

## Outcome

Turn abstract wealth into understandable scenarios: bills a portfolio could support, time to target corpus, FIRE ranges, and the possible future value of repeated spending. Every result is illustrative and driven by visible assumptions.

## Subfeatures

1. Projection foundation and scenario assumptions
2. Bill-Free Future meter
3. Step-up SIP and FIRE simulator
4. Cost-of-delay calculator

## Existing capabilities to reuse

Assets and valuations, recurring contributions, goals, income profile, essential burn, shared integer money rules, and dashboard visualization primitives.

## Product rules

- Separate actual cash yield from modeled sustainable withdrawal.
- Rates are user-visible basis-point assumptions with conservative/default scenarios.
- Contribution timing, annual step-up timing, inflation, tax treatment, and horizon are explicit.
- Do not hard-code a projection table in UI copy.
- Do not use words such as guaranteed, safe return, or assured corpus.
