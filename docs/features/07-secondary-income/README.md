# Secondary Income

## Outcome

Give salaried users a separate view of freelance, consulting, creator, rental, interest, or other secondary income without creating a second ledger. Show how optional routing of that income changes safety and long-term scenarios.

## Subfeatures

1. Income-stream classification
2. Side-hustle dashboard
3. Zero-lifestyle-inflation routing preference

## Existing capabilities to reuse

Income transactions, categories, tags, recurring detection, reports, goals, transfers, projections, and payday plans.

## Product rules

- Classification is metadata on ledger income, not another balance.
- “Route 100%” is a user preference and planning candidate, not an automatic bank action.
- Business revenue and personal spend are not treated as taxable-profit calculations.
- The feature reports gross tracked inflow unless later expense attribution is explicitly designed.
