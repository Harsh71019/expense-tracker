# Behavioral Tools

## Outcome

Translate discretionary purchases into work time and optional future-value scenarios at useful moments without shaming the user or blocking legitimate spending.

## Subfeatures

1. Life-hour calculator
2. Transaction-linked pause and reflection

## Existing capabilities to reuse

Quick-add, transaction detail, salary/work profile, category grouping, spending warnings, projection engine, and toast/dialog primitives.

## Product rules

- Work time uses net in-hand salary and the effective work-hours setting.
- Results are unavailable—not guessed—when required profile data is missing.
- The intervention is shown for discretionary expenses according to user preference and threshold.
- Reflection never blocks saving the transaction and can be disabled.
- Future value is an illustrative opportunity-cost scenario, not a statement of loss.
